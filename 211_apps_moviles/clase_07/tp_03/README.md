# TP N°3: Promedio y nombre de estudiante

## Descripción
Desarrollar una aplicación sencilla en Android con Jetpack Compose que permita ingresar:

- El nombre de un estudiante
- Dos notas numéricas

## Funcionalidades

### Botón 1: Calcular promedio
Al presionar este botón, la app deberá:

- Calcular el promedio de las dos notas
- Mostrar en pantalla el nombre del alumno junto con el resultado obtenido

### Botón 2: Nota de participación
Incluir un segundo botón que:

- Genere una nota aleatoria de participación
- La sume al cálculo final

Esto permitirá observar cómo cambia el estado de la interfaz en función de las acciones del usuario.

## Validaciones requeridas

- El nombre no debe estar vacío
- Las notas ingresadas deben ser numéricas

En caso de error, se deberá mostrar un mensaje adecuado en pantalla.

## Organización del código

Separar la lógica de la aplicación (validaciones y cálculos) de la parte visual construida con composables.

## Objetivo del ejercicio

Practicar:
- Manejo de estado
- Eventos
- Validación de datos
- Primera separación entre vista y lógica dentro de una app simple

## Entrega

- Solamente el código fuente
- Preferentemente en un repositorio de código

## Modalidad

- Individual o grupal
- Máximo 3 estudiantes por equipo
