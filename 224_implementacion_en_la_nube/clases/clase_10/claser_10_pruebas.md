# Pruebas 

# ¿Porqué son importantes las pruebas?
- permiten validar el cto funcional del sitio antes de prd
- ayudan a detectar errores, fallas de intefracion y problemas de experiencia de usuario
- reducen riesgos operativos y mejoran la calidad del servicio
- permiten medir rendimiento, seguridad y compatibilidad


# aspectos claves a evaluar
- rendimiento y tiempos de respuesta
- seguridad ante ataques y vulnerabilidades
  - la idea de seguridad es agregar la mazxima cantidad de capas, para que no suceda
  - que solo reciba usuarios con una cierta estructura, 
  - demasiados intentos de ingreso que lo bloquee
  - que si las solicitud se ahcen de un lugar donde no fue radicada la cuenta pida una validacion
- exactitud de la info mostrada
- compatibilidad en navegadores
- accesibilidad y experiencia de usuario
- escalabilidad bajo carga

# problemas que pueden ocurrir
- enlaces rotos/recursos inexistentes
- diferencias e visualizacion entre navegadores
- formularios con validaciones incorrectas
- errores de busqueda/filtrado
- lentitud bajo alta concurrencia
- fallas de seguridad o permisos

# gestion de errores y participacion de usuarios
al encontrar un error:
- registrar incidentes 
- documentar pasos para producirlas
- informar impacto y frecuencia
- colaborar con el equipo de dev

# tipos de pruebas recomendadas
- funcionales
- de integracion
- de rendimiento y carga
- de seguridad
- de compatibilidad
- de acpetacion de usuario UAT
