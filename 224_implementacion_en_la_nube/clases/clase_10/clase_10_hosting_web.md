# Hosting web

El concepto de `web hosting` se refiere a un espacio físico en un servidor, que está conectado a Internet, y permite almacenamiento y despacho de información (archivos .HTML, JavaScript, css, imágenes, vídeos, etc.) a cualquier visitante. Mientras que el proveedor de `web hosting o ISP` es quien brinda las soluciones o “paquetes” de alojamiento web para que puedas alojar tus datos allí.

> [!NOTE] Note | Hosting
> Cuando se escribe la dirección de un sitio y se cliquea enter en el navegador web, hay un servidor detrás que comienza a despachar toda la información del sitio web para visualizarlo en el navegador: `ese es el concepto de hosting, almacenar y servir información a visitantes que la demandan en tiempo real.`

## Discos
Los discos utilizados para almacenar datos eran los discos `(HDD) IDE, SATA o SCSI`, que funcionaban mecánicamente con sus diferentes partes. 

Desde hace una década existe una nueva tecnología llamada `SSD`, los discos SSD son discos digitales, que funcionan sin partes motoras-mecánicas, y tienen muchas ventajas sobre el disco duro tradicional o hard disk.

Existen diferentes tipos de hosting, pero muchos son comunes a casi todos los proveedores y son hoy por hoy las soluciones más comercializadas, tanto en grandes empresas como en pequeñas que recién comienzan.

A nivel de sistemas operativos, encontraremos dos tipos básicos de hosting web: 

- Servidores Linux
Son más seguros, estables y compatibles con casi todas las tecnologías de la web, pues la web se ha construido sobre Unix y sus derivados como Linux.
Los planes que ofrecen Windows como sistema operativo están orientados a personas que necesitan alojar aplicaciones creadas y servidas específicamente con tecnologías como ASP o MS SQL server de Microsoft.

Tipos de hosting

Web hosting compartido
-  Permitir tener un máximo de 1 sitio online.
-  Brindar espacio, transferencia y recursos para subir tu web.
-  Crear casillas de email y cuentas de FTP.

Alojamiento multidominio (Reseller)
-  Hospedar múltiples sitios web en una sola cuenta.
-  Usar para revender espacio a clientes propios/as.

Cloud VPS o Cloud Hosting
-  Ejecutar servicios y aplicaciones en sistemas operativos virtualizados dentro de servidores dedicados.
-  Brindar independencia de recursos.
-  Utilizar por empresas de desarrollo y desarrolladores/as web / DevOps para subir, probar y poner en producción sus apps.
-  Ofrecer opciones de proveedores gratis y pagos.

Servidores dedicados
-  Alojar información en máquinas físicas destinadas únicamente a una sola persona.
-  Utilizar por empresas con requerimientos de desarrollo y necesidades específicas.
-  Proveer privacidad, independencia de recursos y mayor seguridad.
-  Usar para hosting de imágenes, archivos estáticos o sitios dinámicos con PHP o Python.

Servidores de streaming
-  Alojar y transmitir señales de radio, TV y vídeo online en demanda.
-  Despachar señales por la web para radios y canales con presencia en Internet.

Servidores de juegos online
-  Orientar a jugadores en red para partidas online.
-  Instalar software servidor para que clientes se conecten desde sus hogares y jueguen partidas multijugador interminables.

 

Funcionamiento del hosting

Seguramente cuando escuchás el término `URL` sabés de qué se trata, igualmente vamos a analizar porque es parte fundamental para que el hosting funcione bien.

En primera instancia si no tenés una `URL` definida para tu web, es decir, `un nombre de dominio`, no podrás usar el plan de hospedaje web que hayas contratado.

Las `URLs`, también conocidas como `direcciones web`, son las que utilizás en tu navegador cuando te dirigís hacia google.com, yahoo.com, o cnn.com.



Funcionamiento del hosting
- Al momento de intentar navegar a google.com o tusitio.com, desde tu navegador se contacta a los `servidores DNS públicos`, para luego saltar `al servidor web` y que éste responda despachando el contenido que le solicitaste.
- El servidor web (Apache, Nginx, IIS, etc.) es un software que está en el servidor físico donde alojás tu página, y es el encargado de despachar todo el contenido que los/las visitantes le piden.
- Una vez listo, tu navegador descarga el contenido servido por el servidor web, y podés visualizar la página.

 

¿Cómo obtener un url y elegir un servicio de hosting?
-  Para tener una URL de tu web necesitás contratar un Dominio, la URL http://tusitio.com funcionará únicamente si contratás el nombre de dominio: tusitio.com en un registrante. 
-  La mayoría de los proveedores de Hosting también registran dominios, aunque podés hacerlo por separado si lo deseás.
-  El primer paso para alojar tu proyecto en la nube es elegir el hosting: un servicio que te provee del espacio en Internet para que alojes tus sitios web.
-  Hay muchas cosas a tener en cuenta a la hora de contratar un plan de hosting, como uptime, soporte, idioma, localización de servidores, etc.
