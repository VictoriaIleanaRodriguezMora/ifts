# ¿Qué es CI/CD?
CI (Integración continua)
- automatiza la integración frecuente de código
- detecta errores de forma temprana
- CD(entrega/despliegue cotninuo)
- automatiza la entrega o despliegue de apliaciones

alcance de CI/CD
- estandariza procesos de desarrollo
- reduce errores humanos
- acelera el ciclo de vida del software
- facilita el trabajo colaborativo

> [!NOTE] Note | Despliegue
> La idea es que el despliegue de la integración se haga de manera automatizada y no dependa de que haya una persona que vaya pc por pc a actualizar o dejar el software como precisamos

limitaciones de CI/CD
- configuracion inicial compleja
- dependencia de buenas practicas
- costos de infra
- cultura devops

Ejemplos de uso
- compilación automatica al subir código en una nueva integracion
- ejecucucion de pruebas unitarias
- generacion de artefactos
- despliegue en entornos de prueba o prd


Principales herramientas
- github actions
- jenkins
- azure devops pipelines
- bitbucket pipelines (atlassian - jira)
